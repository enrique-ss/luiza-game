# Um dia Doce

Romance visual interativo (Visual Novel) que utiliza um motor lógico próprio para ramificação de histórias com base nas decisões do jogador. Possui sistema de diálogos dinâmicos, controle de variáveis de estado (afeto e energia do personagem) e múltiplos desfechos narrativos.

Acesse em: [enrique-ss.github.io/luiza-game](https://enrique-ss.github.io/luiza-game)

## Como rodar

Clone o repositório e abra o `index.html` no navegador.

## Documentação e Stack

### Tecnologias
- HTML, CSS e JavaScript puro.
