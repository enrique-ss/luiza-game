## Notas Técnicas para Geração de Imagens

### Formatos Recomendados:
- **Backgrounds**: 800x600 pixels (4:3 aspect ratio)
- **Sprites**: 400x600 pixels (2:3 aspect ratio)
- **Stickers**: 200x200 pixels (1:1 aspect ratio)

### Palavras-chave para Prompts:
- **Estilo**: "indie pixel art", "16-bit style", "vibrant colors", "romantic atmosphere"
- **Iluminação**: "warm lighting", "golden hour", "soft light", "magical atmosphere"
- **Cores**: "warm color palette", "vibrant saturated colors", "reds and pinks for Luiza", "greens for Enrique", "yellows for Talita"

### Ferramentas Sugeridas para Geração:
- **Midjourney**: Para backgrounds detalhados com estilo pixel art
- **DALL-E 3**: Para sprites e stickers com estilo consistente
- **Stable Diffusion**: Para geração em lote com prompts consistentes

### Consistência Visual:
- Manter o mesmo estilo pixel art em todas as imagens
- Usar paleta de cores consistente (vermelho/rosa para Luiza, verde para Enrique, amarelo para Talita)
- Manter a mesma proporção e resolução para imagens do mesmo tipo
- Considerar iluminação consistente baseada no horário do dia
